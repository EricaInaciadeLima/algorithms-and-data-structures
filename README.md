# Algorithms and Data Structures

Repositório dedicado ao estudo prático de **Lógica de Programação, Estruturas de Dados e Algoritmos**, utilizando **Java**.

## 🎯 Visão macro

Este projeto representa uma trilha progressiva de desenvolvimento do **raciocínio algorítmico**.

A proposta não é apenas implementar códigos que funcionam, mas compreender o processo necessário para transformar um problema em uma solução:

```text
Problema
   ↓
Entendimento
   ↓
Entrada e saída
   ↓
Decomposição
   ↓
Algoritmo
   ↓
Implementação em Java
   ↓
Testes
   ↓
Análise de complexidade
   ↓
Otimização
```

O estudo começa pelos fundamentos da lógica de programação e evolui gradualmente para estruturas de dados e algoritmos mais complexos.

### 🧠 Objetivo principal

Desenvolver a capacidade de:

* compreender um problema antes de programar;
* decompor problemas em etapas menores;
* construir algoritmos;
* implementar soluções em Java;
* trabalhar com diferentes estruturas de dados;
* analisar **Time Complexity** e **Space Complexity**;
* comparar diferentes estratégias para um mesmo problema;
* reconhecer padrões de resolução;
* identificar oportunidades de melhoria e otimização.

> **Foco principal:** entender o raciocínio por trás da solução, e não apenas chegar ao código que funciona.

### 📊 Complexidade

Após compreender uma solução, o próximo passo é analisar seu custo computacional.

```text
Time Complexity
      +
Space Complexity
      ↓
Custo da solução
```

A análise busca compreender perguntas como:

* Quantas operações são realizadas?
* Quantas vezes os dados são percorridos?
* Qual é o impacto do tamanho da entrada?
* É necessário utilizar memória adicional?
* Existe uma troca entre tempo e memória?
* Existe outra estratégia com menor custo?

O objetivo é desenvolver a capacidade de **justificar tecnicamente uma solução**, e não apenas classificá-la com uma notação como `O(n)` ou `O(n²)`.

### 🔬 Comparação de soluções

Quando um problema permitir diferentes abordagens, as soluções poderão ser comparadas considerando:

```text
Solução A
    ↓
Custo de tempo
    +
Custo de memória

        VS

Solução B
    ↓
Custo de tempo
    +
Custo de memória
```

A intenção é compreender **por que** uma solução possui determinado custo e quais são os impactos das escolhas realizadas.

### 🌱 Evolução do aprendizado

Este repositório funciona como um registro da evolução do raciocínio algorítmico.

A intenção é sair de:

```text
"Como escrevo esse código?"
```

para perguntas como:

```text
"Qual é o problema?"
        ↓
"Qual é a entrada?"
        ↓
"Qual é a saída?"
        ↓
"Como posso decompor o problema?"
        ↓
"Qual algoritmo representa essa solução?"
        ↓
"Qual estrutura de dados faz sentido?"
        ↓
"Qual é o custo dessa solução?"
        ↓
"Posso melhorar?"
```

Assim, o projeto acompanha uma evolução que começa na **lógica de programação** e gradualmente chega à capacidade de analisar e construir soluções algorítmicas mais complexas.
